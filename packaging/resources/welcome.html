FanBoost 🌀

A menu bar app that spins up your Mac's fans before it gets hot, shows what heated it up, and can cap battery charging.

This installer will:

  • add FanBoost to Applications and start it at login,
  • add the fanctl helper to /usr/local/bin,
  • let your user run only fanctl as administrator without a password (needed to change fan speed), via /etc/sudoers.d/fanboost.

To remove it later, run sudo fanboost-uninstall in Terminal.

Apple Silicon support is experimental. Open source (MIT): github.com/amarpathak/fanboost
